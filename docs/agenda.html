About the workshop

kadi-apy is the Python library and command line tool of Kadi4Mat. It allows routine steps of the web interface, such as creating records, uploading files, adding metadata and searching, to be scripted. This is useful whenever the same steps are repeated for many files, for example after a measurement series.

We apply it to a tensile test campaign with three steel specimens (synthetic data): the result files are uploaded, calculated values such as the yield strength are stored as metadata, and the data is found and plotted again. The same steps apply to other instruments and file types. No prior experience with kadi-apy or Python is required.

Preparation and material

Before the workshop (about 20 minutes): create a personal access token in Kadi4Mat (kadi4mat.iam.kit.edu, Settings > Access tokens), open the notebook in Google Colab, store the token as a Colab secret named KADI_PAT and run the setup cells. A step-by-step checklist is in the participant guide.
