TermWhat it means for you
RecordOne "thing" you want to document: a sample, a measurement, a simulation run. Holds files and metadata.
MetadataStructured facts about a record: key (name), type (text, number, ...), value and unit. Searchable, unlike numbers buried in a file.
CollectionA folder-like group of records, e.g. a project or test campaign.
TagA keyword label for finding records later.
IdentifierA unique short name for a record, e.g. jd-sample-s01. Unique across all of Kadi4Mat, so we put your initials in front.

What is kadi-apy?

A remote control for Kadi4Mat. Anything you can click in the website, kadi-apy can do for you, for one file or for a thousand.

Website
Click by hand. Fine for a few records.
Command line
kadi-apy records ...
One command per action. Easy to repeat.
Python
from kadi_apy import ...
Loops, calculations, reading your files.
Where it saves you time: uploading a whole folder of instrument files at once; extracting results (e.g. yield strength) into metadata automatically; consistent names and tags for the whole group; finding and downloading data for a report or paper.

Using the command line (CLI)

With the CLI you control Kadi4Mat by typing short commands instead of clicking. Every command has the same structure:

kadi-apythe program
recordswhat: records, collections, ...
add-metadatumthe action
-R jd-sample-s01 -m length -v 80 -t float -u mmoptions: -letter value, the details of the action

Where to type it

In Colab: in a code cell, with ! in front:

!kadi-apy records --help

On your own computer: in a terminal (Windows: Anaconda Prompt or Command Prompt; macOS: Terminal), without !. One-time setup:

pip install kadi-apy
kadi-apy config create    # new config
kadi-apy config set-host  # Kadi4Mat URL
kadi-apy config set-pat   # your token

Three rules

Text with spaces goes in quotes: -t "Steel sample S01".
Upper and lower case matter: -R is not -r.
Forgot an option? Add --help to any command.

Options used today

kadi-apy cheat sheet

Command line (in Colab, put ! in front)

# create a record
kadi-apy records create -i jd-sample-s01 -t "Sample S01"
# upload a file (or a whole folder)
kadi-apy records add-files -R jd-sample-s01 -n data/tensile_tests/S01_tensile.csv
# add metadata with type and unit
kadi-apy records add-metadatum -R jd-sample-s01 -m specimen_length -v 80 -t float -u mm
# add a tag
kadi-apy records add-tag -R jd-sample-s01 -t jd-tensile-campaign
# show metadata (-m) and file list (-l)
kadi-apy records show-info -R jd-sample-s01 -m -l
# find records by tag / list all commands
kadi-apy records get-records -t jd-tensile-campaign
kadi-apy records --help

Python

from kadi_apy import KadiManager
manager = KadiManager()                       # your login (reads the config)

# get the record, or create it if it does not exist yet
record = manager.record(identifier="jd-sample-s01", title="Sample S01", create=True)

# metadata: a list of dictionaries (key, type, value, unit)
record.add_metadata([{"key": "specimen_length", "type": "float",
                      "value": 80.0, "unit": "mm"}], force=True)

record.upload_file("data/tensile_tests/S01_tensile.csv", force=True)   # upload a file
record.add_tag("jd-tensile-campaign")                    # add a tag

# put the record into a collection
collection = manager.collection(identifier="jd-campaign", title="Campaign", create=True)
record.add_collection_link(collection.id)
